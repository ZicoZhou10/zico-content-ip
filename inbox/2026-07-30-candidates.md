## Candidate 3: Coinbase 让 AI Agent 开始付钱——全球第一个允许商家直接收取 AI Agent USDC 支付的金融基础设施（July 23, 2026）

- **Event**: 2026年7月23日，**Coinbase Business** 推出支付基础设施，允许商家通过 **x402 协议**直接接受 AI Agent 以 **USDC** 发起的支付，AI Agent 可在 Base 或其他链上即时结算。**x402 协议**由 Coinbase 孵化，是 HTTP 原生的稳定币支付标准——Agent 可以像做 API 调用一样完成支付，无需人类介入结算流程。**工作流**：AI Agent 读取商家文档 → 创建钱包 → 接受资金 → 向商家发起 USDC 支付 → 在 Base 链上结算，全程无人类审批节点。商家通过单一 Coinbase Business 账户管理全部 Agent 支付。**规模**：已有约 **5,000 家商家**接入，创造合计约 **$10 亿**的支付与交易量（支付 + 交易合并）。Coinbase 将其定性为「**最高置信度的押注**」（most high-conviction bet）。**背景**：此前 AI Agent 支付问题的行业解法一直是给 Agent 绑定人类的信用卡或企业账户——Agent 以「人类的名义」付款。x402 的区别是：商家账单的收款方就是 Agent 本身，不是人。来源：CoinDesk（July 23：「Coinbase closes the gaps in AI agent economy for businesses, users and developers」）| The Block（「Coinbase calls AI payments its 'most high-conviction bet' as businesses begin accepting agent payments」）| CryptoBriefing（「Coinbase enables AI agents to pay businesses and execute crypto trades」）| Bitcoin.com（「Coinbase Rolls Out AI Agents Payment for Businesses in USDC, Calls it a 'High-Conviction Bet'」）| Coinpaprika（「Coinbase Makes AI Payments Its Top Bet as Agents Start Buying」）| Crowdfund Insider（July 23：「Coinbase Enables Businesses To Accept Payments From AI Agents」）

- **Zico's angle**: 先把这件事最不直观的部分说清楚：之前 AI Agent 付款的通行做法是把人类的信用卡或企业账户绑给 Agent，Agent 以「人类的名义」完成支付，账单记在人类头上。Coinbase x402 做的是完全不同的事：**商家收款对象是 Agent 本身**。Agent 有自己的钱包，Agent 自己读文档、创建交易、用自己的 USDC 结账。这不只是「更方便的支付 UX」，这是经济主体身份的一次实质性扩展——Agent 从「代理人类行事的工具」变成了「能独立发起和完成经济交易的主体」。这件事对 Agent 经济的基础设施含义是：如果 Agent 有独立的支付能力，整个「AI 作为消费者」的经济模型就不再只是理论。过去几年的讨论一直停在「AI Agent 作为生产工具」层面——它帮人类干活，人类付钱买算力。x402 以下的世界里，Agent 开始有自己的预算、自己的交易记录、自己的支付身份。这是 Agent 经济从「AI 作为手段」到「AI 作为经济参与者」的第一个有规模的基础设施节点。为什么是 Coinbase 而不是 Stripe/Mastercard？x402 是加密原生协议，USDC + Base 链意味着：即时结算（传统信用卡 T+2）、无退款风险（链上不可逆）、可编程（合约可以加条件）。这三个属性对 Agent 支付特别重要，因为 Agent 交易的频率和规模会远超人类手工支付，传统支付的摩擦系数在这个量级下会成为瓶颈。加密原生的路径不是偶然，是 Agent 支付需求的结构性选择。
- **Resonance hook**: 7月23日，Coinbase 上线了一个功能：商家可以直接收到 AI Agent 打来的 USDC。不是人帮 Agent 付款，是 Agent 自己付款——Agent 创建钱包，读商家文档，发起交易，链上结算。5,000 家商家已接入，合计 $10 亿交易量。Coinbase 说这是「最高置信度的押注」。这是第一次有受监管的金融机构建设了 Agent 作为独立付款方的基础设施。「AI Agent 作为消费者」这个论断，这周有了第一个有规模的配套支付轨道。
- **Recommended priority**: high
